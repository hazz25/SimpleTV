# Simple TV

Lecteur IPTV simple pour Android TV, Google TV, Fire TV et box Android, avec un code Xtream.

- Accueil à grandes tuiles : TV en direct, Films, Séries, Favoris, Recherche
- TV en direct en 3 colonnes : catégories, chaînes, aperçu
- Films et séries avec affiches, reprise de lecture et épisode suivant automatique
- Favoris (appui long), catégories masquables (appui long), historique

L'application ne fournit aucun contenu : elle lit uniquement l'abonnement saisi par l'utilisateur.

## Installer sur la TV

1. Installez l'application **Downloader** et autorisez-la à installer des applications inconnues.
2. Dans Downloader, saisissez l'adresse :
   `https://github.com/<utilisateur>/simpletv/releases/latest/download/SimpleTV.apk`
3. Installez, ouvrez Simple TV et saisissez votre code Xtream.

Chaque modification du code produit automatiquement un nouvel APK (onglet **Actions**, puis **Releases**).
Pour mettre à jour, refaites l'étape 2 : la nouvelle version s'installe par-dessus l'ancienne.

## Utilisation à la télécommande

| Écran | Touche | Action |
|---|---|---|
| TV en direct | OK sur une chaîne | Aperçu à droite |
| TV en direct | OK une 2ᵉ fois | Plein écran |
| Partout | Appui long sur OK | Ajouter / retirer des favoris |
| Catégories | Appui long sur OK | Masquer la catégorie |
| Plein écran (direct) | ▲ ▼ ou CH+ CH− | Changer de chaîne |
| Plein écran (direct) | OK | Voir le programme en cours |
| Film / épisode | ◀ ▶ | Reculer 10 s / avancer 30 s |
| Film / épisode | OK | Pause, pistes audio, sous-titres |
